## Milestone Summary

Built a compliance-aware RAG assistant for HK investment advisers in five phases. The foundation establishes auth, RBAC, and audit infrastructure (SFC-mandated from day one). Ingestion and query pipelines follow. Telegram is the primary adviser interface — it delivers the full Q&A and human-review workflow. The React web UI is an audit and admin tool for compliance officers and admins, not a chat interface.

### Key Accomplishments

1. JWT auth + role-based access control with Qdrant pre-filtering enforcing sensitivity tiers at the DB layer
2. Full document ingestion pipeline: docling parsing (PDF/Word/Excel) → LLM semantic chunking → text-embedding-3-small → Qdrant with RBAC metadata
3. RAG query pipeline: query rewrite (DeepSeek) → Voyage AI embeddings → Qdrant RBAC retrieval → cohere reranking → DeepSeek generation with inline citations
4. Telegram bot as primary adviser interface: Q&A with source citations, Approve/Edit/Discard inline keyboard, full audit write-back
5. React web dashboard: audit log browser, full trace inspector, document registry, admin ingestion UI

### Key Decisions

| Decision | Outcome |
|----------|---------|
| Qdrant over ChromaDB | ✓ Pre-filtering enforces RBAC at DB layer — correct security model |
| Audit trail in Phase 1 | ✓ SFC regulatory requirement; progressive lifecycle (received→retrieved→generated→completed) worked well |
| Telegram as primary interface | ✓ Inline keyboard for draft review is the right UX for mobile advisers |
| React web UI as audit/admin only | ✓ Separation of concerns; compliance officers get dedicated tool |
| docling for document parsing | ✓ Single library covers PDF/Word/Excel; structured markdown output ideal for RAG |
| DeepSeek V4 for generation | ✓ Strong instruction-following; compliance system prompt effective |
| Voyage AI for embeddings | ✓ Better retrieval quality than text-embedding-3-small for financial docs |
