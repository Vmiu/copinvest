# Phase 5 — UI Design Contract

> Visual and interaction contract for the Web Audit & Admin UI. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Design System

| Property | Value |
|----------|-------|

## Spacing Scale

Declared values (multiples of 4 only):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, badge padding, inline gaps |
| sm | 8px | Compact row padding, button icon gap |
| md | 16px | Default cell padding, form field spacing |
| lg | 24px | Section padding, card padding |
| xl | 32px | Layout column gaps |
| 2xl | 48px | Major section breaks between page regions |
| 3xl | 64px | Page-level top/bottom padding |

Exceptions:
- Sidebar width: 240px (fixed, not on scale — layout constraint)
- Touch targets: minimum 44px height for all interactive controls (accessibility)
- Table row height: 48px minimum (readability for compliance review)

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 12px | 400 (regular) | 1.4 |
| Body | 14px | 400 (regular) | 1.5 |
| Heading | 18px | 600 (semibold) | 1.2 |
| Display | 24px | 600 (semibold) | 1.2 |

Notes:
- Monospace font (font-mono) for trace inspector raw fields: query_text, prompt_sent, llm_response, retrieved_chunks JSON. Size: 12px, weight 400, line-height 1.6.
- Table column headers: 12px label size, weight 600 (semibold), uppercase tracking-wide.
- Sensitivity tier badges: 12px label size, weight 600 (semibold).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | neutral-950 (`#0a0a0a`) | Page background, main content area |
| Secondary (30%) | neutral-900 (`#171717`) | Sidebar background, table row hover, card surfaces |
| Accent (10%) | indigo-500 (`#6366f1`) | See reserved list below |
| Destructive | red-500 (`#ef4444`) | Destructive actions only (none in Phase 5) |
| Border | neutral-800 (`#262626`) | Table borders, card borders, dividers |
| Muted text | neutral-400 (`#a3a3a3`) | Secondary labels, timestamps, metadata |
| Success | emerald-500 (`#10b981`) | Ingestion success state |
| Warning | amber-500 (`#f59e0b`) | Ingestion warnings, not_found flag |

Accent (indigo-500) reserved for:
- Active sidebar nav item (left border indicator + text)
- Primary action buttons: "Ingest Document" submit button
- Pagination current page indicator
- Row-level "View Trace" link text
- Filter "Apply" button

Accent is NOT used for: table headers, badges, status indicators, hover states on non-primary actions.

Sensitivity tier badge colors (semantic, not accent):
- Public: emerald-500 background, neutral-950 text
- Internal: blue-500 background, neutral-950 text
- Restricted: amber-500 background, neutral-950 text
- Confidential: red-500 background, white text

## Layout

### Navigation Shell

- Left sidebar, fixed, 240px wide, full viewport height
- Sidebar background: neutral-900
- Logo/app name at top: 64px header area, 24px display weight
- Nav items: 4 items, 44px height each, 16px horizontal padding
- Active item: indigo-500 left border (3px), indigo-500 text, neutral-800 background
- Inactive item: neutral-400 text, transparent background, hover → neutral-800 background
- Nav items (in order):
  1. Audit Log — icon: `ClipboardList` — route: `/audit`
  2. Document Registry — icon: `FolderOpen` — route: `/documents`
  3. Ingest Document — icon: `Upload` — route: `/ingest`
  4. (Trace Inspector is a detail view only — no nav item — route: `/audit/:trace_id`)
- Main content area: left margin 240px, padding 32px, background neutral-950

### Page Structure

Each page: Display heading (24px) + optional subtitle (14px muted) at top, then content region below with 24px gap.

## Component Contracts

### Audit Log Table (UI-01)

Columns (in order): Timestamp | User | Channel | Query | Status | Adviser Action

| Column | Width | Notes |
|--------|-------|-------|
| Timestamp | 160px | Format: `YYYY-MM-DD HH:mm` in user's local timezone |
| User | 140px | user_id or display name |
| Channel | 80px | Badge: "web" (neutral) or "telegram" (blue-400) |
| Query | auto (flex) | Truncated at 80 chars with ellipsis, full text in tooltip |
| Status | 100px | Badge: success/error/not_found |
| Adviser Action | 120px | Badge: sent/discarded/saved/pending |

Row behavior:
- Entire row is clickable, cursor pointer
- Hover: neutral-900 background
- Click: navigate to `/audit/:trace_id`
- No checkbox selection (read-only view)

Filter bar (above table):
- Date range: two date inputs (from / to), 140px each
- User filter: text input, 180px, placeholder "Filter by user"
- Session filter: text input, 180px, placeholder "Session ID"
- Apply button: indigo-500, "Apply Filters"
- Clear button: ghost variant, "Clear Filters"
- Filters are server-side — each Apply triggers a new API call

Pagination:
- Below table, right-aligned
- Shows: "Showing 1–25 of 142 records"
- Prev / Next buttons + page number display
- Page size: 25 records (fixed, not configurable in Phase 5)

### Trace Inspector (UI-02)

Route: `/audit/:trace_id`

Back navigation: "← Audit Log" link at top-left, 14px body, neutral-400, navigates to `/audit` (preserves no filter state in Phase 5).

Page heading: "Trace: {trace_id}" (display 24px). Subheading: timestamp + user + channel (14px muted).

Layout: single column, full width, collapsible sections stacked vertically with 16px gap.

Collapsible sections (in order):

| # | Section Label | Default State | Contents |
|---|---------------|---------------|----------|
| 1 | Query | Open | `query_text` (mono), `rewritten_query` (mono, labeled "Rewritten"), `not_found` flag (amber badge if true) |
| 2 | Retrieved Chunks | Collapsed | JSON array of retrieved_chunks rendered as formatted JSON in mono block; chunk count shown in section header |
| 3 | Prompt Sent | Collapsed | `prompt_sent` full text in mono block, scrollable max-height 400px |
| 4 | LLM Response | Open | `llm_response` full text in body font (not mono), scrollable max-height 400px |
| 5 | Adviser Action | Open | `adviser_action` badge + `final_response` if present |
| 6 | Metadata | Collapsed | `model_used`, `prompt_tokens`, `completion_tokens`, `sensitivity_tier_accessed`, `channel`, `session_id` — rendered as key/value pairs in a 2-column grid |

Collapsible section header: 16px body weight 600 (semibold), chevron icon right-aligned, full-width clickable, 48px height, neutral-800 border-bottom.

`not_found` flag: if true, show amber-500 badge "No chunks retrieved" in section 1 header and in the page subheading area.

### Document Registry (UI-03)

Columns: Filename | Type | Sensitivity Tier | Chunks | Ingested At | Ingested By

| Column | Width | Notes |
|--------|-------|-------|
| Filename | auto (flex) | Full filename, no truncation unless >60 chars |
| Type | 80px | Badge: PDF / DOCX / XLSX |
| Sensitivity Tier | 120px | Colored badge per tier color contract above |
| Chunks | 80px | Right-aligned integer |
| Ingested At | 160px | Format: `YYYY-MM-DD HH:mm`, sortable |
| Ingested By | 140px | user_id |

Default sort: `ingested_at` descending (most recent first). Source: D-11 + user decision.

Sort behavior: clicking "Ingested At" column header toggles asc/desc. Sort icon (ChevronUp/ChevronDown) shown in active sort column header only.

Filter bar (above table):
- Sensitivity tier: Select dropdown, options: All / Public / Internal / Restricted / Confidential
- Filter is client-side (document list is not expected to exceed 500 rows in Phase 5)
- No pagination in Phase 5 — full list rendered (add pagination in a future phase if needed)

### Ingest Document Form (UI-04)

Single-column form, max-width 480px, centered in content area.

Fields (in order):
1. File picker — label "Document", accepts `.pdf,.docx,.xlsx`, required
2. Sensitivity tier — Select dropdown, label "Sensitivity Tier", options: Public / Internal / Restricted / Confidential, required, no default (force explicit choice)
3. Submit button — full width, label "Ingest Document", indigo-500, disabled while request in-flight

In-flight state (D-08):
- Submit button replaced by spinner + "Ingesting..." label
- File picker and tier select disabled
- No timeout — request may take 30–60s; spinner persists until response

Success state (D-09):
- Green alert below form: "Document ingested successfully"
- Show IngestResponse fields inline: Document ID, chunk count, any warnings (amber text if warnings present)
- Form resets to empty — user can submit another file immediately
- Alert dismissible via X button

Error state (D-10):
- Red alert below form: error message from API response
- Form fields remain populated (user can correct and resubmit)
- Alert dismissible via X button

## Accessibility

- All interactive elements meet 44px minimum touch target height
- Color is never the sole differentiator — badges include text labels alongside color
- Collapsible section triggers use `aria-expanded` and `aria-controls`
- Table columns with sort use `aria-sort` attribute
- Focus ring: 2px indigo-500 outline, 2px offset, on all focusable elements
- Sidebar nav items use `aria-current="page"` for active item
- Form fields have explicit `<label>` associations (not placeholder-only)
- Sensitivity tier select has no default — user must make an explicit choice (prevents accidental Public ingestion of Confidential docs)
