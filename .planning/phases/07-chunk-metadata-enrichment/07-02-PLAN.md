# Plan 07-02: Ingestion service + vector repo wiring

## Objective

Wire the new metadata fields end-to-end: ingest router accepts 5 new form fields, passes them through `ingestion_service.ingest_document()`, which consumes the new `list[dict]` from `chunk_document()` and stores computed fields in Qdrant payload + doc-level fields in `document_registry`. Add 3 new Qdrant payload indexes. Extend document list endpoint with `document_type` and `jurisdiction` filter params.

## Threat Model

<threat_model>
- **T-01 (LOW):** New form fields are optional at the API layer for backward compat — but document_type, language, jurisdiction are required per UI-SPEC. Enforce required validation in the router.
- **T-02 (LOW):** `product_codes` stored as JSON text in DB — parse on read to avoid returning raw JSON string to frontend.
- **T-03 (LOW):** Qdrant `create_payload_index` is idempotent — safe to call on existing collection with existing indexes.
</threat_model>

```python
async def list_documents(
    db: AsyncSession,
    document_type: str | None = None,
    jurisdiction: str | None = None,
) -> list[DocumentRecord]:
    q = select(DocumentRecord).order_by(DocumentRecord.ingested_at.desc())
    if document_type:
        q = q.where(DocumentRecord.document_type == document_type)
    if jurisdiction:
        q = q.where(DocumentRecord.jurisdiction == jurisdiction)
    result = await db.execute(q)
    return list(result.scalars().all())
```

@router.get("/documents", response_model=DocumentListResponse)
async def list_documents_endpoint(
    document_type: str | None = Query(None),
    jurisdiction: str | None = Query(None),
    db: AsyncSession = Depends(get_db),
    current_user: dict = Depends(require_role("adviser", "senior_adviser", "admin")),

    docs = await document_repo.list_documents(db, document_type=document_type, jurisdiction=jurisdiction)

        if d.product_codes:

            item.product_codes = json.loads(d.product_codes)
        items.append(item)
    return DocumentListResponse(items=items, total=len(items))
