### 2. DocumentRegistry — extend filter bar and table

**Filter bar layout:** `flex items-center gap-3 mt-6 mb-4` (unchanged). Append 2 new Select filters after the existing Sensitivity Tier filter.

**New filters:**

| Filter | Width | Options |
|--------|-------|---------|
| Document Type | `w-44` | All / Factsheet / Compliance Document / Meeting Template / Research Report / Other |
| Jurisdiction | `w-36` | All / Hong Kong / Singapore / Global |

Both selects: `bg-neutral-800 border-neutral-700 text-white` (same as existing tier filter).

Default value for both: `"all"` (shows "All" via `<SelectValue placeholder="All types" />` and `<SelectValue placeholder="All jurisdictions" />`).

**New table columns — exact order after existing columns:**

Current columns: Filename | Type | Sensitivity Tier | Chunks | Ingested At | Ingested By

New columns inserted between "Type" and "Sensitivity Tier":

| Column | Header | Width | Cell rendering |
|--------|--------|-------|----------------|
| `document_type` | "Doc Type" | `w-32` | `<Badge variant="secondary">{item.document_type ?? "—"}</Badge>` |
| `language` | "Lang" | `w-16` | `text-neutral-300 text-xs uppercase` — render raw value (`en`, `zh`, `other`) or `"—"` if null |
| `jurisdiction` | "Jurisdiction" | `w-24` | `text-neutral-300 text-xs` — render raw value (`HK`, `SG`, `global`) or `"—"` if null |
| `product_codes` | "Product Codes" | `w-40` | `text-neutral-300 text-xs` — join array with ", "; truncate to 30 chars with "…" if longer; render `"—"` if empty |
| `parent_doc_title` | "Display Title" | no fixed width | `text-neutral-300` — truncate to 50 chars with "…" if longer; render `"—"` if null |

Final column order: Filename | Doc Type | Lang | Jurisdiction | Product Codes | Display Title | Sensitivity Tier | Chunks | Ingested At | Ingested By

**Skeleton loading:** Update skeleton rows to match new column count (10 columns). Pattern: `Array.from({ length: 5 }).map(...)` with `Array.from({ length: 10 })` inner cells.

**Empty state (no documents):** Copy unchanged — "No documents ingested" heading + "No documents have been ingested yet. Go to Ingest Document to add the first one." with `<Link to="/ingest" className="text-indigo-500 hover:underline">`.

**Empty state (filters active, no results):** New case — when filters produce zero results from a non-empty dataset:
- Heading: "No documents match the selected filters"
- Body: "Try clearing the Document Type or Jurisdiction filter."
- No link. `colSpan` matches new column count (10).

**Error state copy:** "Failed to load documents. Refresh to try again." (unchanged).

**Filter interaction:** All three filters (tier, document_type, jurisdiction) are applied client-side with `useMemo` — AND logic (all active filters must match). No server round-trip on filter change.

## Accessibility Requirements

- All `<Select>` components use shadcn's Radix-based implementation — keyboard navigation and ARIA roles are provided by the library.
- New table `<TableHead>` cells do not need `aria-sort` unless they are sortable. Only "Ingested At" is sortable; new columns are not sortable.
- All `<input>` fields have an associated `<label>` via `htmlFor` / `id` pair.
- Helper text paragraphs are associated with their input via `aria-describedby` (add `id` to helper `<p>` and `aria-describedby` on the `<input>`).
- Disabled state on all form fields during loading is conveyed via `disabled` attribute (not just visual styling).
- Truncated cell content (product_codes, parent_doc_title, filename) does not require a tooltip in this phase — truncation is cosmetic only.
